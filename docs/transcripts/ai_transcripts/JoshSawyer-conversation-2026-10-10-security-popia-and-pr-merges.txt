> where do i add the &sslmode=require is the last line is pgbouncer=true

⏺ Let me answer that directly since it's time-sensitive for Task 2, then
  come back to the CI reproduction.

  The `&sslmode=require` goes at the very end of the entire connection
  string, after `pgbouncer=true` — not as a separate line. If your
  DATABASE_URL currently looks like:

  postgresql://user:password@host:6543/postgres?pgbouncer=true

  it becomes:

  postgresql://user:password@host:6543/postgres?pgbouncer=true&sslmode=require

  So: find the `?pgbouncer=true` part, and append `&sslmode=require`
  directly after it with no space, no new line — just tack it onto the same
  string. The `&` is correct here because `?pgbouncer=true` already opened
  the query-string with one parameter.

  For DIRECT_URL, check whether it already has a `?` in it:
  - If it has no `?` at all yet, use `?sslmode=require`.
  - If it already has a `?`, use `&sslmode=require` instead.
