## Recommended package

Use `axe-core@^4.13.0` directly as a web dev dependency.

Why:

- It has built-in TypeScript declarations and no dependencies.
- It can scan a rendered DOM element directly in jsdom.
- It avoids adding Jest-specific dependencies to a Vitest project.
- Stable `vitest-axe` is still `0.1.0` and several years old; its newer line is prerelease.
- `jest-axe` is well maintained, but brings Jest matcher utilities into a Vitest suite unnecessarily.
- Playwright is not necessary for this acceptance criterion.

Deque documents that axe can run against DOM elements rendered by component-testing tools. It also notes that jsdom cannot reliably test visual rules such as color contrast, so this would catch semantic/ARIA issues but would not replace browser and manual accessibility testing.
