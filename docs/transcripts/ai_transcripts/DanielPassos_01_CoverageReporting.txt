## Current request flow

1. The frontend runs at `http://localhost:5173`.
2. `AuthStatus` calls `signInWithGoogle()`.
3. That helper makes the same call previously used directly by `AuthStatus`:

```ts
authClient.signIn.social({
  provider: "google",
  callbackURL: window.location.href,
});
```

4. The auth client sends the request directly to:

```text
http://localhost:4000/auth
```

5. BetterAuth constructs Google’s callback as:

```text
http://localhost:4000/auth/callback/google
```

6. After authentication, BetterAuth redirects back to the URL passed as `callbackURL`, normally the page where Sign in was clicked.

The helper is therefore only an extraction of the existing behavior. It has not changed the provider, API origin, callback URL, or redirect behavior.
